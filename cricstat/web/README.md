# cricstat/web — public pages (P0.4)

Static pages served by Nginx at `/cricket/` (bind mount `cricstat/web → /var/www/cricket:ro`).
Every number comes from `/cricket/api` (cricstat-api, F5) in the browser; nothing here is generated.

| Page | Path | Script |
|---|---|---|
| Hub | `/cricket/` | `assets/hub.js` |
| Players (search + profile) | `/cricket/players/`, `/cricket/players/<name>-<8-hex id>/` | `assets/players.js` |
| Countries | `/cricket/countries/`, `/cricket/countries/<team-slug>/` | `assets/countries.js` |
| Data & licences (F8) | `/cricket/licences/` | — |

- Design: the approved F2 wireframes (India blue `#1347A3`, saffron `#FF9933`), system fonts (no third-party fonts).
- No inline scripts (ready for an enforced CSP); Chart.js is the self-hosted copy in `website/vendor/`.
- DOM is built with `textContent` only (`cricstat.h()`), never `innerHTML` with data.
- Ratios are cut to 2 decimals, not rounded (F4 R23, `cricstat.ratio()`).
- Browser storage: only `cricstat:follow` (localStorage), listed on the privacy page. No cookies.
- Page shells (`**/index.html`) are generated by `cricstat/tools/gen_pages.py`: edit that, never the HTML. After any
  CSS/JS change bump `V` there (the `?v=` on asset URLs; pages are cached for an hour) and rerun it.
- Shared helpers in `assets/cricstat.js`: `sectionTabs()` (board tabs), `scoreText()` (scoreboard digits),
  `carousel()` (‹ › strips), `freshness()` (Cricsheet update notice),
  `teamBadge()`/`teamLine()` (flags), `roleIcon()`, `formatCard()`, `periodControl()`. Defaults: YTD + ODI.
- About drawer: text in `about.json` (edit wording there), script `assets/about.js` (textContent only; Mermaid
  self-hosted, loaded on first open).
- Flags: `assets/flags.js` + `flags/` come from `cricstat/tools/fetch_flags.py` (PD/CC0 only); never board logos.

Preview locally (nothing public): `python3 cricstat/tools/web_preview.py` → http://127.0.0.1:8090/cricket/
(serves these pages, the staged homepage/privacy/sitemap from `cricstat/tools/staging/`, and proxies the API).
